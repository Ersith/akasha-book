## 三、优先级加固清单

**P0（先做，风险最低收益最高）**
1. **拿到管理员上下文，审计 Defender 排除项**（确认没有历史留的口子）；
2. **复核 Windows Update 实际状态**（`Get-HotFix` 不全，改用更新状态查询）确认补丁没断档；
3. **收窄四个第三方监听**（WPS / Wacom / Steam / Eagle）—— 逐项确认是否必需，非必需改"仅本机"或停用。

**P1**
4. **SMB 面处理**：无共享需求 ⇒ 关闭 SMB Server 服务；需保留 ⇒ 防火墙规则限定**仅私有网段**，并在 Public 档拒绝；
5. **入站规则审计**：列出所有 `Enabled + Allow + Inbound` 的自定义规则（排除系统默认），逐条确认必要性。

**P2**
6. **日志与告警**：开 PowerShell 脚本块日志（4104）/ 关键事件转发，形成"可回看"；
7. **备份与恢复**：确认系统还原点/关键配置备份的可用性（防勒索的第一道是"救得回来"）；
8. **学习=威胁模型**：以 CyberStrikeAI 的攻击面为教材（`tools/` 100+ 工具配方、`knowledge_base/` 注入笔记、`c2.md`、`security-model.md`）→ 产出**攻击面 → 对应控制**的对照表（防御视角），逐条落到本机。
