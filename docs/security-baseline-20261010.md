## 二、真实暴露面（26 条里的重点）

| 监听 | 进程 | 判读 / 建议 |
|---|---|---|
| `139` on `192.168.31.116` + `172.21.128.1`、`445` on `::` | System | **SMB/NetBIOS 对局域网可见** ⇒ 家用网内横向移动的主要面。**建议**：若无共享需求，关闭 SMB 服务或防火墙仅允许私有网段；**WSL 网段**(172.21.128.x) 也能看到它 |
| `135`（0.0.0.0/::）、`5040`、`49664`(lsass)、`49665`(wininit)、`5357`(WSDAPI)、`7680` | 系统服务 | 系统自带，受防火墙入站默认策略保护；可逐条确认无自定义放行 |

## 三、优先级加固清单

**P0（先做，风险最低收益最高）**
1. **拿到管理员上下文，审计 Defender 排除项**（确认没有历史留的口子）；
2. **复核 Windows Update 实际状态**（`Get-HotFix` 不全，改用更新状态查询）确认补丁没断档；
3. **收窄四个第三方监听**（WPS / Wacom / Steam / Eagle）—— 逐项确认是否必需，非必需改"仅本机"或停用。

**P1**
4. **SMB 面处理**：无共享需求 ⇒ 关闭 SMB Server 服务；需保留 ⇒ 防火墙规则限定**仅私有网段**，并在 Public 档拒绝；
5. **入站规则审计**：列出所有 `Enabled + Allow + Inbound` 的自定义规则（排除系统默认），逐条确认必要性。

**P2**
6. **日志与告警**：开 PowerShell 脚本块日志（4104）/ 关键事件转发，形成"可回看"；
7. **备份与恢复**：确认系统还原点/关键配置备份的可用性（防勒索的第一道是"救得回来"）；
8. **学习=威胁模型**：以 CyberStrikeAI 的攻击面为教材（`tools/` 100+ 工具配方、`knowledge_base/` 注入笔记、`c2.md`、`security-model.md`）→ 产出**攻击面 → 对应控制**的对照表（防御视角），逐条落到本机。

## 四、需要用户配合的两件

1. **一次性管理员权限**（用于 P0-1/P0-2 与 P1 的规则审计；只读为主，改动前逐条报）；
2. **四个第三方监听的取舍**（WPS / Wacom / Steam / Eagle：哪些你日常要用）。

## 五、边界声明（沿用我们的"守不住的"诚实口径）

- 本基线的探测**只覆盖本机当前状态**，不含路由器/局域网内其它设备；
- `NotConfigured` 的防火墙默认动作＝系统默认，本机策略层**没有**额外加严；
- **Defender 排除项与更新状态这两格本机查不到/不全**，本报告**不冒充已核**；
- 本报告是**体检**不是**加固完成**——加固动作逐条经用户确认后执行，并记录变更。
