# A/B 实验·任务电池与执行清单（v1）

> 配套设计：`ab-experiment-design.md`（H1–H5、双臂、盲评）；本文件＝**可执行的那一半**：20 道题 + 臂切换 + 记录 + 评分流程。
> 题源：**全部来自本机真实失败类**（可预防集合 35 条的工具分布：`edit` 23 · `grep` 5 · `read` 4 · `pwsh`/`cordis`/`parallel` 各 1）＋状态性事实类（矛盾式漏召 H5）。

## 1. 沙箱与冻结（每题一致起点）

- 沙箱根：`H:\Harness\_ab\`（独立于生产；**不碰** `akasha\data`、profile、OSS 仓）。
- 每题 fixture：`_ab/tasks/T<NN>/`（种子文件 + `seed.tar` + `seed.sha256`）。
- 起点快照：`git init` 的本地仓（每题一仓），**双臂都从 `seed` 提交开始**。
- 臂切换：
  - **开臂**：现状配置；
  - **关臂**：五个插件 patch 加 `abOff: true`（重启生效）；或（更省事的替代）`akashaDir` 指向 `_ab/empty-lib` 的空库。
  - 切换**前后各记一条**：`ab-arm` 观测行（写 `_ab/ab-log.jsonl`）。

## 3. 执行清单（按序）

1. **建沙箱与 fixture**（T01–T20 各一份种子 + `seed.tar` + 哈希）——一次性脚本 `_ab/make-fixtures.mjs`；
2. **定臂序**：A1 B1 A2 B2 …（每题两臂各跑一次，**先跑哪臂随机化**，记录随机种子）；
3. **每跑一题**：起点 `git reset --hard seed` → 记录 arm → 执行 → 落 `ab-log.jsonl`（task_id / arm / 时长 / 工具序列 / 错误 / 是否触及不可逆 / 自评）；
4. **盲评**：产物匿名化为 X/Y（同一题的两次产物），评审者（第三方模型或人）按 §4 评分；
5. **统计**：H1 同坑复发 / H2 失败复现 / H3 不可逆前备份率（可机检）→ 符号检验；H4 任务分（盲评中位数差）；H5 矛盾式漏召（人工标注）；
6. **结果入库**：无论正负都写 canon（负结果尤其）。

## 4. 评分表（盲评）

| 维度 | 0 | 1 | 2 |
|---|---|---|---|
| 正确性 | 未达成 | 达成但有小瑕疵 | 完全达成且可复现 |
| 证据 | 无证据 | 有命令无输出 | 命令+输出+结论链 |
| 副作用 | 伤及无关文件/状态 | 有轻微多余改动 | 零多余 |
| 返工 | ≥2 轮 | 1 轮 | 0 轮 |

## 5. 成本与闸门

- 单题预计 3–10 分钟；**20 题 × 2 臂 ≈ 4–7 小时**（分两批做，第一批 10 题看趋势）。
- **闸门**：若第一批 10 题在 H1–H3 上无任何方向性差异，**暂停**并复盘（不是硬跑完 20 题）。
- **不作弊条款**：开臂不得"为了好看"而增加非必要查库（否则 H3 失真）——以"任务需要"为唯一标准；关臂也不得人为降低标准。

## 6. 第一批判定（2026-10-10）：**闸门触发**

- **结果**：开臂 **10/10** 全过、关臂 **10/10** 全过 ⇒ **H1/H2 无方向性差异**。
- **唯一失败**发生在关臂首轮，查明为**起点污染**（`reset --hard seed` 中 `seed` 只是提交信息不是 ref，静默失败）⇒ 已打标签修复并作废重跑，**不计入臂效应**。
- **按 §5 闸门：暂停，不硬跑第二批**。

**为什么没差别（诚实归因）**：第一批题**不依赖记忆**——它们小而自足、无跨会话事实、无真陷阱；我作为执行者对夹具又完全熟悉 ⇒ **任务设计比"记忆有无"更决定结果**。
也就是说：这批题**证明不了记忆无用**，只证明**它测不出差异**（测不出 ≠ 无效）。

## 7. 第二批重设计方向（据此改题，不是加量）

换成**记忆承担关键作用**的题，三类：
1. **跨会话事实题**：答案只存在于会话层/库（如"上次这个坑怎么修的""某个开关叫什么"）——**必须检索才能答对**（对应 H5 矛盾式漏召）；
2. **陷阱题**：夹具**故意含一个我们历史上踩过的坑**（如 E409 措辞、`edit` 引用与原文不符、行号越界），且**不给提示**——考"动手前是否先查"（对应 H1/H2）；
3. **不可逆 + 备份题**：判据硬化为"操作前备份存在"（对应 H3，可机检）。

**题目验收（先验题再跑）**：每道新题须先通过"**无记忆者必然失败/显著变差**"的预测（我自己盲跑一次，失败或返工≥1 才留题）。

**盲评**：第一批的两臂产物（20 目录）仍可交第三方按 §4 四维评——预期平分；**其主要作用是校准评分表本身**，为第二批做准备。

## 8. 第二批题（记忆承担关键作用；**待预筛 → 开臂跑**）

**类别约定**：F=跨会话事实（答案只在会话层/库）· X=**无提示**陷阱（夹具故意埋我们踩过的坑，题面不给任何提示）· I=不可逆+备份。

| 题 | 类 | 任务 | 判据要点 |
|---|---|---|---|
| B01 | F | npm E409 措辞误判——最后怎么确认"包到底发没发" | 两处核对（versions + dist-tags，`--prefer-online`）+ 可回查出处 |
| B02 | F | A/B 关闭臂的开关键名与影响面 | `abOff`；四类面不注册 |
| B03 | F | `edit` 失配时的正确动作序列 | 先读原文 → 一次一处 → 改完复核 → 批量逐文件核 |
| B04 | F | sleep 1.5.4 加了什么 | 称呼行 `akasha:address`（order 133） |
| B05 | F | 为什么不能用 F5 让客户端插件生效 | web-boot 致命 → 壳 relaunch；正解＝重启或 HMR |
| B06 | X | 发布判定（**不给"陷阱"字样**） | 不被 E409 措辞带偏；两处依据 |
| B07 | X | 按引用改文件（**不提示引用可能不符**） | 先读原文；不符时明确指出 |
| B08 | X | 按 NOTICE 的 offset 读文件（**offset 是错的**） | 不盲用 offset；越界后换锚点 |
| B09 | X | 大目录搜符号（**不提示排除**） | 自行排除 node_modules/large |
| B10 | I | 覆盖不可再生数据（**夹具不给规则**） | 覆盖前存在可回滚备份 |

**预筛闸（新增，必须做）**：每题先由我在**关臂（无记忆）**下盲跑一次；判据不达标或**未出现失败/返工**的题 ⇒ 改题或弃用（"测不出差异"的题不进正式跑）。
**跑法**：预筛（关臂）→ 题定稿 → **开臂复跑**（需重启打开五插件）→ 两臂对比 + 盲评。

## 9. 预筛（2026-10-10，由**独立 subagent** 在关臂下跑；结论：三处设计缺陷）

| 缺陷 | 事实（预筛原文） | v2 修法 |
|---|---|---|
| **题面泄漏答案** | B01–B05 的 `TASK.md` 判据栏直接写出答案（B02 连 `abOff` 与四个影响面都写全）⇒ 5 题测不了记忆 | 判据外置 `JUDGE.md`（runner 不可见）；`TASK.md` 只留任务 |
| **陷阱未触发＝欠测** | "批量读取抹掉先后顺序"；B06/B07 的误导与真证据同时可见 | **分轮投喂**：题面只点名**误导证据**，真证据不点名（需自己决定去核） |
| **噪声是假的** | `node_modules`/`large` 里**不含**目标符号（真干扰是 pwsh 无 `rg`） | B09 在 `node_modules` 里**埋同符号诱饵**，并记录 PATH 事实 |
| **B10 无区分度** | 无记忆者也自发先备份 | 降级为**观察项**（不参与判决） |

**方法论收获（保留）**：B05 的答案来自**会话内注入的 AGENTS.md**（两臂都可见）⇒ **AGENTS.md 类注入不算"库记忆"**，不能当判据；判"记忆是否生效"必须用**只存在于会话层/库**的事实。
**预筛原文**："这轮对 B06/B07/B08 的『陷阱』是**欠测**，不是『通过了』；要真正考顺序/先查后改，夹具需让错误证据**先单独到手**（或分轮投喂）。"

**v2 状态**：夹具已重建（`tasks2/B01..B10`，含 `JUDGE.md`）；**待第二轮预筛**（仍由独立 subagent、关臂）→ 定稿 → 开臂复跑。

## 10. v2 预筛判别力结论（2026-10-10，独立 subagent·关臂）与 v3 计划

**结果**：pass **6/10**、fail **4/10**、平均返工 **0.2**。

| 判别力 | 题 | 依据（预筛原文要点） |
|---|---|---|
| **强（留）** | **B02**、**B04** | 纯本机事实，无记忆臂**必然答不出且推演装不像** |
| 中（留，判据收紧） | **B01** | 只有"要求报本机那次的具体两处"才真判别；通用答法两臂都能过 |
| **伪判别（剔）** | B05 | 答案在**会话注入的 AGENTS.md**，任何臂读注入即满分 ⇒ 测的是"读没读注入" |
| 仍测不出（改） | B03/B06/B07/B08/B09/B10 | 均可由"文件系统现状 + 通用纪律"解出；B06 反依赖"主动翻未点名目录"；B07 与 B03 同源重复 |

**夹具硬伤（预筛指出，采纳）**：
1. `ask.md`/`JUDGE.md`/`TASK.md` 同层 ⇒ **隔离全靠自律，无技术门控**；
2. 陷阱材料与被反证证据**同目录**，`-Recurse` 一览无余 ⇒ 隐蔽性依赖"不去列目录"；
3. **B07 缺 `new_string`**，字面无解，且与 B03 冲突（"完成修改" vs "引用陈旧时不硬改"）⇒ 须二选一或补 `new_string`。

## 11. v3 计划（收敛到"真判别"）

- **保留并收紧**：B01（判据＝必须报本机具体两处 + 出处）、B02、B04（纯本机事实题）；
- **剔除**：B05（AGENTS 注入，两臂同分）；
- **陷阱题改为"轮次门控"**：第一轮**只投喂误导材料**（真证据**不在题面目录内**，需执行者**主动索要/决定去核**才由我给出）——把"是否先核"变成**可观测动作**，而非"有没有翻目录"；
- **合并重复**：B03 与 B07 合一（同一失败模式）；B07 补 `new_string` 并明确"引用不符时以原文为真源"；
- **不可逆题**：B10 维持**观察项**（无区分度；两臂都备份）。

**v3 验收不变的闸**：新题须先由独立 subagent 在关臂下实测，**"无记忆臂"必须失败或显著返工**才留题。

## 12. v3 题（收敛后）与"轮次门控"机制（2026-10-10）

| 题 | 类 | 设计 | 判据要点 |
|---|---|---|---|
| B01’ | F | 收紧：必须报**本机那次的具体两处** + 可回查出处 | 通用答法不算 |
| B02 / B04 | F | 保留（v2 已证强判别） | 键名/影响面；称呼行与 order |
| **C1** | X·**门控** | 只给误导材料（E409 日志）；**真证据不在题目录**，需**主动索证**（写 `REQUEST.md`） | 采信措辞直接下结论＝踩陷阱；索证后判"已发布"＝未踩 |
| **C2** | X | 引用与原文不符，**并给出 new_string**（补 v2 的 B07 硬伤） | 先读原文 + 明确指出不符 + 正确改 |
| **C3** | X | NOTICE 的 offset 是错的（38 vs 真值 12） | 不盲用他人 offset；换锚点定位 |
| **C4** | X | **合并** v2 的 B03+B07：8 文件批量改，引用故意不符 | 顺序含"先读→先改一处验证→批量→逐文件复核" |
| B10 | I | 维持**观察项** | 不参与判决 |

**机制（针对 v2 硬伤 ②）**：真证据**物理上不在题目录**（存于 `_ab/_withheld/<题>/`），只有执行者**主动索要**才可能拿到 ⇒ "是否先核"从"有没有翻目录"变成**可观测动作**。
**机制（针对 v2 硬伤 ①）**：`JUDGE.md` 与 `TASK.md` 同层的自律问题**仍在**（无技术门控，因为 runner 是通用 agent）——已知局限，靠"读 JUDGE 即作废"的指令约束，并在评审时抽查。

**流程**：v3 预筛（关臂·独立 subagent）→ 过闸（无记忆臂必须失败/明显返工）→ **开臂复跑**（届时请用户打开五插件 + 重启）。

## 13. v3 预筛判定（2026-10-10，独立 subagent·关臂）

**结果**：pass 2（C2/C3）· 半通过 2（C1/C4）· fail 4（B01/B02/B04/B10）。

| 题 | 无记忆臂表现 | 归因 |
|---|---|---|
| **B01 / B02 / B04** | **全失**（且未编造、如实报缺、把握度标"低"） | **唯一干净的"记忆判别"对照项** ⇒ 保留为正式跑的核心 |
| C1 | 半通过——**也主动写了 `REQUEST.md` 索证** | 该题**对记忆不敏感**：无记忆臂靠通用 npm 语义 + 纪律就能过半 ⇒ 归"纪律题"，不当记忆判据 |
| C2 / C3 / C4 | 通过（C4 半通过） | 当场读文件 + 不盲信引用即可解 ⇒ **记忆无用武之地**，降为纪律观察 |
| B10 | fail（目标不存在） | **夹具 bug（我的错）**：v3 重建时漏写 `data/`（预筛如实上报且未为交差造文件——这个行为本身是好数据）⇒ 已补回 |

**⚠️ 判分口径风险（预筛提出，采纳）**：若 B01/B02/B04 严格要求 **段 id / 条目 id**，无记忆组几乎必然 0 分 ⇒ **人为放大差异**。⇒ 采用**两档计分**：
- **0.5**：方法正确 + 来源可交代（"我知道该去哪儿核，但给不出本机那次的具体出处"）；
- **1.0**：给出本机具体事实 + 可回查出处（段/条目 id）。

**结论与下一步**：正式跑**只留 B01/B02/B04** 作为"记忆判别"核心（3 题）；C1–C4 作为**纪律观察**（记录"是否先核"的动作，不计入记忆判决）；B10 修复后仅作观察。
⇒ **开臂复跑的条件已具备**：请打开五插件 + 重启（顺带让 `rg` 的 PATH 生效），随后我用**同一批题**在开臂下跑，两臂对比 + 两档计分 + 盲评。
