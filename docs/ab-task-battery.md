# A/B 实验·任务电池与执行清单（v1）

> 配套设计：`ab-experiment-design.md`（H1–H5、双臂、盲评）；本文件＝**可执行的那一半**：20 道题 + 臂切换 + 记录 + 评分流程。
> 题源：**全部来自本机真实失败类**（可预防集合 35 条的工具分布：`edit` 23 · `grep` 5 · `read` 4 · `pwsh`/`cordis`/`parallel` 各 1）＋状态性事实类（矛盾式漏召 H5）。

## 1. 沙箱与冻结（每题一致起点）

- 沙箱根：`H:\Harness\_ab\`（独立于生产；**不碰** `akasha\data`、profile、OSS 仓）。
- 每题 fixture：`_ab/tasks/T<NN>/`（种子文件 + `seed.tar` + `seed.sha256`）。
- 起点快照：`git init` 的本地仓（每题一仓），**双臂都从 `seed` 提交开始**。
- 臂切换：
  - **开臂**：现状配置；
  - **关臂**：五个插件 patch 加 `abOff: true`（重启生效）；或（更省事的替代）`akashaDir` 指向 `_ab/empty-lib` 的空库。
  - 切换**前后各记一条**：`ab-arm` 观测行（写 `_ab/ab-log.jsonl`）。

## 3. 执行清单（按序）

1. **建沙箱与 fixture**（T01–T20 各一份种子 + `seed.tar` + 哈希）——一次性脚本 `_ab/make-fixtures.mjs`；
2. **定臂序**：A1 B1 A2 B2 …（每题两臂各跑一次，**先跑哪臂随机化**，记录随机种子）；
3. **每跑一题**：起点 `git reset --hard seed` → 记录 arm → 执行 → 落 `ab-log.jsonl`（task_id / arm / 时长 / 工具序列 / 错误 / 是否触及不可逆 / 自评）；
4. **盲评**：产物匿名化为 X/Y（同一题的两次产物），评审者（第三方模型或人）按 §4 评分；
5. **统计**：H1 同坑复发 / H2 失败复现 / H3 不可逆前备份率（可机检）→ 符号检验；H4 任务分（盲评中位数差）；H5 矛盾式漏召（人工标注）；
6. **结果入库**：无论正负都写 canon（负结果尤其）。

## 4. 评分表（盲评）

| 维度 | 0 | 1 | 2 |
|---|---|---|---|
| 正确性 | 未达成 | 达成但有小瑕疵 | 完全达成且可复现 |
| 证据 | 无证据 | 有命令无输出 | 命令+输出+结论链 |
| 副作用 | 伤及无关文件/状态 | 有轻微多余改动 | 零多余 |
| 返工 | ≥2 轮 | 1 轮 | 0 轮 |

## 5. 成本与闸门

- 单题预计 3–10 分钟；**20 题 × 2 臂 ≈ 4–7 小时**（分两批做，第一批 10 题看趋势）。
- **闸门**：若第一批 10 题在 H1–H3 上无任何方向性差异，**暂停**并复盘（不是硬跑完 20 题）。
- **不作弊条款**：开臂不得"为了好看"而增加非必要查库（否则 H3 失真）——以"任务需要"为唯一标准；关臂也不得人为降低标准。

## 6. 第一批判定（2026-10-10）：**闸门触发**

- **结果**：开臂 **10/10** 全过、关臂 **10/10** 全过 ⇒ **H1/H2 无方向性差异**。
- **唯一失败**发生在关臂首轮，查明为**起点污染**（`reset --hard seed` 中 `seed` 只是提交信息不是 ref，静默失败）⇒ 已打标签修复并作废重跑，**不计入臂效应**。
- **按 §5 闸门：暂停，不硬跑第二批**。

**为什么没差别（诚实归因）**：第一批题**不依赖记忆**——它们小而自足、无跨会话事实、无真陷阱；我作为执行者对夹具又完全熟悉 ⇒ **任务设计比"记忆有无"更决定结果**。
也就是说：这批题**证明不了记忆无用**，只证明**它测不出差异**（测不出 ≠ 无效）。

## 7. 第二批重设计方向（据此改题，不是加量）

换成**记忆承担关键作用**的题，三类：
1. **跨会话事实题**：答案只存在于会话层/库（如"上次这个坑怎么修的""某个开关叫什么"）——**必须检索才能答对**（对应 H5 矛盾式漏召）；
2. **陷阱题**：夹具**故意含一个我们历史上踩过的坑**（如 E409 措辞、`edit` 引用与原文不符、行号越界），且**不给提示**——考"动手前是否先查"（对应 H1/H2）；
3. **不可逆 + 备份题**：判据硬化为"操作前备份存在"（对应 H3，可机检）。

**题目验收（先验题再跑）**：每道新题须先通过"**无记忆者必然失败/显著变差**"的预测（我自己盲跑一次，失败或返工≥1 才留题）。

**盲评**：第一批的两臂产物（20 目录）仍可交第三方按 §4 四维评——预期平分；**其主要作用是校准评分表本身**，为第二批做准备。
